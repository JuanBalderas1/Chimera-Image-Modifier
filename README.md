# Automatic Image Resizer


A simple desktop GUI tool built that allows users to resize images individually or in bulk with preview functionality. 


## Features


- Resize a single image with custom width and height (in pixels). 
- Bulk resize entire folders of images. 
- Maintain aspect ratio option.
- Comes with 3 preset size options (Thumbnail, Medium, HD).
- Preview images before saving (for single image and in bulk). 
- Supports JPG and PNG formats. 


## How to Run


1. Clone the repository:
- git clone https://github.com/JuanBalderas1/automatic-image-resizer.git 

2. Navigate into the folder:
- cd automatic-image-resizer

3. Install Dependencies:
- pip install -r requirements.txt

4. Run the program:
- python main.py


## Output


- All resized images are saved into a folder named: "Resized Images".
